# 类 Danbooru 现代画廊图库应用 — PRD

> 本文档只描述**需求、约束与验收标准**。技术设计见同目录 `design.md`。

---

## 1. 项目定位

一个**个人自用**的动漫图片图库应用,核心目标是"**比 Danbooru 更美观**"的浏览体验。

- 单用户(自用),不做多人社区/协作。
- 数据来源:本地文件夹导入 + Danbooru 抓取(架构预留多源)。
- 重点是**图片管理 + 标签系统 + 沉浸式浏览 UI**。

## 2. 目标与非目标

### 目标(本期)
1. 沉浸式深色画廊 UI(瀑布流浏览 + lightbox 详情)。
2. 完整的标签系统:分类着色、计数、implication 语义(搜索自动展开)、UI 树状折叠展示。
3. Danbooru 风格搜索语法子集(AND / NOT / OR / 通配 / 分级过滤)。
4. 安全模式(默认开启,三档分级 safe/questionable/explicit)。
5. 本地文件夹导入(增量扫描 + 去重)。
6. Danbooru 抓取(按标签/ID,限速,多源预留)。
7. 收藏夹(图集)管理。
8. 单用户登录(首次向导 + cookie 会话)。

### 非目标(本期不做)
- 评分/打分(score 功能已剔除)。
- 评论、Wiki、笔记(Notes)。
- 多用户、权限分级、上传审核、社交协作。
- 自动打标签(ML 模型,留作未来扩展)。
- 视频支持(仅静态图 + 动图 GIF/APNG/WEBP 动画)。
- 搜索语法的高级元标签(`width:>1000`、`source:`、`id:` 等)。

## 3. 用户故事

- **作为使用者**,我想用深色沉浸界面浏览图库,让图片成为视觉主角,而非被密集表格干扰。
- **作为使用者**,我想用标签组合搜索(AND/NOT/OR/通配),快速定位特定主题的图。
- **作为使用者**,我想从本地文件夹批量导入图片,且自动去重,不必手动逐张处理。
- **作为使用者**,我想从 Danbooru 按标签抓取图(带标签、来源、分级),扩充我的图库。
- **作为使用者**,我想把喜欢的图整理进收藏夹(图集),按自定义顺序浏览。
- **作为使用者**,我想用安全模式过滤成人内容,默认只看 safe 图。
- **作为使用者**,我想用密码保护图库,不裸奔在局域网。

## 4. 功能需求

### F1. 浏览页(瀑布流主页)
- 无边框瀑布流(CSS columns),等宽列、按高度排布,极小 gap(4px)。
- hover 卡片浮现控件:收藏 ★、分级色块(右下角)、疑似重复标记(左上角)。
- 顶栏(半透明毛玻璃,滚动渐隐,hover/置顶复现):Logo、搜索框、安全模式开关、登录、导入入口、设置。
- 左侧可滑出抽屉:标签筛选(按类型折叠 + 热门标签云,点击即加入搜索)。
- 无限滚动(IntersectionObserver 加载下一页)。

### F2. 详情页(lightbox 沉浸)
- 黑底全屏,图片主体在**右侧/居中**。
- **左侧**半透明浮层信息面板,**默认精简**(ID/尺寸/标签按类型分组首行),可"展开全部"。
- implication 折叠树:父标签可展开看 implied 子标签。
- 标签着色:character 蓝 / copyright 紫 / artist 黄 / general 灰 / meta 青。点击标签跳转搜索。
- 键盘导航:← → 翻页,F 收藏,E 编辑,Esc 返回。
- 动图自动循环播放,点击暂停/播放。
- 编辑模式:增删标签、改分级、加入图集。

### F3. 标签页 `/tags`
- 按类型(category)分组:角色/作品/作者/通用(各自可折叠)。
- 每个标签显示 post_count,按计数排序。
- implication 父节点可展开看 implied 子标签。
- 点击标签 → 跳转浏览页搜索该标签。

### F4. 标签搜索
- **本期仅实现 `tag1 tag2` 交集(AND)** + `rating:safe|questionable|explicit` 分级过滤。
- `NOT`(`-tag1`) / `OR`(`~tag1 ~tag2`) / 通配符(`tag1*`)为**后续版本**,本期不做。
- 搜索在 `post_tags` 上做 AND 匹配——因连带关系在写入时已算实展开(见 `docs/adr/0001-implication-materialized-at-write-time.md`),读时无需递归 CTE,行为上仍为"递归展开"(打 miku 命中 vocaloid)。
- 安全模式开启时,所有查询自动追加 `rating:safe`(**后端全局注入**)。
- 搜索框 chip 化:输入的标签变成彩色 chip(按类型着色,排除项红边),下拉自动补全。

### F5. 本地导入
- 选择本地文件夹,递归扫描支持的格式(png/jpg/webp/gif/apng)。
- 增量扫描:记录已扫描路径 + 文件 mtime,二次扫描只处理新文件。
- 去重:md5 精确去重(完全相同跳过,不建记录);phash 感知哈希(Hamming 距离 < 阈值,默认 8)在导入后异步计算,命中近似则标记为重复图并填 `duplicate_of_id` 指向原图。重复图**仍入库但在主视图默认隐藏**,可在专门视图查看,仍可被收藏。
- 本地图导入时**无标签**,导入后由用户手动打标签。
- 进度反馈:处理数/总数/重复数,前端轮询任务状态。

### F6. Danbooru 抓取
- 输入查询(标签 / post_id / URL),指定数量,启动抓取任务。
- 调 Danbooru 公共 API(匿名,限速 1 req/s,失败指数退避重试)。
- 抓取每张图的:原图、标签(含 category)、source_url、rating。
- implication 关系:从 Danbooru tags 端点批量拉取,入库(建库拉一次,之后增量)。
- 抓取器抽象(`scrapers/base.py`),Danbooru 为首个实现,预留 gelbooru/moebooru。
- 复用本地导入的媒体处理管道(去重/缩略图/入库)。

### F7. 收藏夹(图集)
- 多个收藏夹(像播放列表),每个有名字。
- 图可加入/移出收藏夹,收藏夹内可调排序(position)。
- 系统为拥有者自动维护一个**默认收藏夹**,"星标"动作 = 加入/移出默认夹。
- **不统计收藏次数**——`Post` 上不设 `fav_count` 字段,是否收藏过只通过 `favorite_items` 成员关系判断(见 `.trellis/spec/backend/quality-guidelines.md`)。

### F8. 单用户登录
- 首次启动:DB 无 user 记录 → 访问任意页重定向 `/setup` → 设置用户名+密码(bcrypt)→ 自动登录。之后 `/setup` 不可访问。
- 登录:校验 bcrypt → 签发 session token,存 HttpOnly cookie。
- 所有 `/api/*`(除 `/api/auth/login`)强制校验 cookie。
- 未登录 → 401 → 前端跳 `/login`。

## 5. 约束

- **技术栈**:Next.js 15(App Router + TypeScript)前端;FastAPI(Python 3.11+)后端;SQLAlchemy 2.0 + SQLite(WAL 模式)。
- **架构**:前后端分离(方案 A),两个独立进程。
- **媒体格式**:png/jpg/webp/gif/apng(动图保留动画)。
- **运维**:个人部署,追求零/低运维。无需 Redis/Celery 等重型依赖(用 APScheduler 轻量任务)。
- **语言**:文档与 UI 交互文本优先中文;代码标识符与注释英文。

## 6. 验收标准

### AC1. 浏览体验
- [ ] 浏览页为无边框瀑布流,深色主题,顶栏滚动渐隐。
- [ ] hover 卡片显示收藏/分级/重复标记控件。
- [ ] 无限滚动加载下一页正常。
- [ ] 安全模式默认开启,关闭后显示全部分级。

### AC2. 详情页
- [ ] 点击瀑布流卡片进入 lightbox 详情页。
- [ ] 图片主体在右侧,左侧浮层默认精简,可展开全部。
- [ ] implication 父标签可折叠展开看子标签。
- [ ] 标签按类型着色,点击跳转搜索。
- [ ] ← → 翻页、F 收藏、E 编辑、Esc 返回快捷键生效。
- [ ] 动图自动播放,点击可暂停。

### AC3. 标签搜索
- [ ] 本期支持 `tag1 tag2` AND + `rating` 过滤语法(NOT/OR/通配为后续版本)。
- [ ] 安全模式开启时自动追加 `rating:safe`。
- [ ] implication 行为上递归展开(打 miku 命中 vocaloid)——机制为写入时算实(`post_tags` 存展开集),非读时递归(见 ADR-0001)。
- [ ] 搜索框 chip 化 + 自动补全。

### AC4. 本地导入
- [ ] 选文件夹递归扫描支持的格式。
- [ ] 增量扫描(二次只处理新文件)。
- [ ] md5 完全重复跳过;phash 相似标记为重复图(填 `duplicate_of_id`,主视图默认隐藏)。
- [ ] 进度反馈(处理数/总数/重复数)。

### AC5. Danbooru 抓取
- [ ] 按标签抓取指定数量图,含标签/source/rating。
- [ ] 限速 1 req/s,失败重试。
- [ ] implication 关系入库。
- [ ] 抓取器为可扩展抽象(Danbooru 为首个实现)。

### AC6. 收藏夹
- [ ] 可创建多个收藏夹。
- [ ] 图可加入/移出,可调排序。
- [ ] "星标"动作通过默认收藏夹实现;不统计收藏次数(无 `fav_count` 字段)。

### AC7. 单用户登录
- [ ] 首次启动 `/setup` 向导创建唯一用户。
- [ ] 登录后 cookie 维持会话。
- [ ] 未登录访问受保护 API 返回 401 并跳转登录。
- [ ] 所有 API(除 login)需认证。

## 7. 范围拆分说明

本任务为**父任务**(多个可独立验证的交付物)。实现阶段应拆为子任务,建议拆分(详见 `design.md` 第 7 节):
- 后端骨架 + 数据模型 + 单用户认证
- 标签搜索编译器
- 媒体处理管道(缩略图/去重)
- Danbooru 抓取器
- 前端骨架 + 浏览页瀑布流
- 详情页 lightbox
- 标签页 + 搜索框
- 导入页 + 收藏夹

每个子任务独立 prd/design/implement,独立验证。
